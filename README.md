# Foundations of IoT Experiments

This repository contains IoT laboratory experiments based on 8051 and STM32 microcontroller platforms. It covers embedded C programming, sensor interfacing, displays, actuators and communication protocols such as UART, I²C, SPI, Wi-Fi and MQTT.

## Experiment Documentation

Each experiment folder contains a `README.md` documenting the following details:

- Experiment ID, date and title
- Task number and objective
- Hardware platform and microcontroller used
- Sensors, peripherals and pin connections
- Circuit diagram, linked using a relative path (where applicable)
- Brief explanation of the implementation and core logic
- Observations, inference and conclusion

Relevant source code and project configuration files are included wherever applicable to help understand and reproduce each experiment.

For 8051 experiments, this includes embedded C source files, Keil project files and startup code. For STM32 experiments, this includes STM32CubeMX `.ioc` files, application source code and required drivers.

Hardware connections, communication interfaces, bus configurations and data flow are also documented wherever relevant.
